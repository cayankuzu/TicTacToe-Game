# Tic Tac Toe

NumPy ile geliştirilen özgün Tic-Tac-Toe çalışmasının tarayıcıda oynanabilen sürümü.

İki oyuncu aynı cihazda sırayla X ve O yerleştirir. Satır, sütun ve iki çaprazın toplamlarını kontrol eden özgün kazanma mantığı web arayüzünde korunur.

## Web sürümü

`index.html` dosyasını açarak kurulum yapmadan oynayabilirsiniz.

## Özgün çalışma

- `TicTacToe.ipynb`: açıklamalı Colab/Jupyter defteri
- `TicTacToe.ipynb - Colab.pdf`: defterin PDF çıktısı

Web sürümü saf HTML, CSS ve JavaScript kullanır.
